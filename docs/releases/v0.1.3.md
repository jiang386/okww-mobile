# v0.1.3 更新说明

把「调设置」搬进游戏内，解决部分设备不支持小窗、退出游戏会导致云会话重排的问题。

## 新增

- **悬浮控制台升级**：
  - 第一排：状态、校准、开始 / 停止、关闭
  - 第二排：`云 / 战斗 / 拾取 / 剧情 / 切人 / 锁定` 六个任务开关，点击立即生效并保存
- **游戏内添加按键**：
  - 悬浮窗点「校准」后，显示一层半透明覆盖层，游戏画面仍然可见
  - 直接点游戏里真实按钮的位置即可添加，留标记并自动切到下一个键
  - 右上「完成」保存并恢复悬浮窗；长按「校准」清空全部按键
- 添加按键期间引擎自动暂停并显示「正在添加按键，已暂停」，避免误点
- 应用内「说明」与 README 同步更新

## 提示

- 悬浮窗需要「显示在其他应用上层」权限
- 「×」关闭悬浮窗即恢复纯手动，不影响游戏本身
