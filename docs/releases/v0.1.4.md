# v0.1.4 更新说明

新增**鸣潮手机端（官方客户端）**适配，并改为 GitHub Release 附件发布。

## 新增

- 主界面新增 **「打开鸣潮手游」**：自动识别并启动
  - `com.kurogame.mingchao`（官服）
  - `com.kurogame.mingchao.bilibili`（B 服）
  - 未安装时提示「未检测到鸣潮手机端」
- `AndroidManifest` 增加对应 `<queries>`，Android 11+ 可正常查询与拉起
- 手机端与云·鸣潮共用同一套能力：
  - 血条颜色检测、自动战斗 / 拾取 / 剧情、自动切人、锁定
  - 悬浮窗任务开关、游戏内点按添加按键、游戏模式（横屏 / 亮度 / 免打扰 / 沉浸）
- 「云断线守护」仅对云·鸣潮有意义，手机端可关闭
- README 增加「两种使用场景」对比，并链接本目录的历史版本更新说明

## 发布方式

- 从本版本起，APK 作为 **Release 附件** 发布（不再把 APK 提交进仓库）
- 历史版本更新说明以附件形式一并发布：
  - `v0.1.0.md`、`v0.1.1.md`、`v0.1.2.md`、`v0.1.3.md`、`v0.1.4.md`

## 安装选择

- 标准版（targetSdk 35）：大多数设备
- 兼容版（targetSdk 32）：realme / ColorOS 等隐藏「允许受限设置」入口的机型
