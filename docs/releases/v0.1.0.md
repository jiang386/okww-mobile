# v0.1.0 更新说明

首个公开版本：把 PC 端 OKWW 的自动化思路迁移到 Android。

## 新增

- 纯 Kotlin 工程（AGP 8.7.3 / Kotlin 2.0.21 / minSdk 26 / targetSdk 35）
- **屏幕采集**：MediaProjection + VirtualDisplay + ImageReader，长边压到 1280、100ms 节流，旋转自动重建
- **手势注入**：无障碍 `dispatchGesture`，无需 root / Xposed
- **视觉识别**：血条颜色检测（普通怪 / Boss）+ ML Kit 离线中文 OCR（模型内置于 APK）
- **云断线守护**：识别「云服务错误 / 1020 / 连接中断」自动重试，排队安静等待，进入游戏 / 复苏自动点击
- **自动战斗**：血条进入战斗后按节奏释放普攻 / 技能 / 解放 / 声骸，可自动切人、可选锁定
- **自动拾取**：OCR 识别吸收 / 拾取 / 采集等提示，黑名单排除误判
- **自动跳过剧情**：对白区密度识别，优先「跳过」
- **Via 游戏模式**：锁横屏、最高亮度、免打扰、沉浸全屏（需一次性 adb 授权）
- **悬浮控制台**：游戏内随时开始 / 停止、查看状态
- **按键校准**：14 个可拖拽点位，归一化坐标
- 双安装包：标准版（targetSdk 35）与侧载兼容版（targetSdk 32，绕过受限设置）

## 已知限制

- 未在真机完整验证，默认坐标需校准
- 云游戏存在串流延迟，识别与点击有天然滞后
