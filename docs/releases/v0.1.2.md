# v0.1.2 更新说明

取消默认键位，改为首次进入后按实际画面点按添加。

## 变更

- **不再内置任何默认坐标**：`KeyPoint` 不携带默认值，配置初始化为空
- 校准页改为「添加」模式：
  - 底部按键条显示 13 个按键，`○` 未添加 / `✓` 已添加
  - 点选按键后在画面上点按钮中心即放置，自动跳到下一个未添加按键
  - 已放置点可拖动微调，「测试点击」验证落点
  - 新增「清空按键」，可整体重来
- 未添加的按键**一律不点击**（剧情推进不再盲点屏幕）
- 开启自动战斗但未添加「普攻」时拒绝启动并提示
- README 新增「推荐游玩方式」：全屏 + 横屏 + 游戏模式；说明竖屏 / 带浏览器工具栏形态可用但不推荐
- 明确保留完整触屏操作：应用不在屏幕上添加任何按钮、不遮挡 UI

## 已知限制

- 竖屏 / 全屏 / 横屏下按钮位置不同，每种模式需各自添加一套点位
